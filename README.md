# 🌐 TrueLens — AI Fake Information Detector

TrueLens is an advanced AI-powered web application designed to detect fake news, rumours, and misinformation in real-time. Users can paste any text, and the system analyzes it using AI techniques to provide a verdict, confidence score, explanation, and supporting sources.

---

## 🚀 Features
### 🔍 AI Detection System
- Paste any news, claim, or statement
- Real-time analysis simulation
- Verdict types:
  - 🔴 Likely False / Rumour  
  - ✅ Verified Information  
  - ⚠️ Unverified / Uncertain  
- Confidence score (0–100%)
- Explainable AI with highlighted phrases

### 🧠 Explainable AI
- Highlights misleading or incorrect words
- Gives reasoning behind verdict
- Shows supporting sources

### 📰 News Dashboard
- Trending News with confidence scores
- Latest News updates
- Multiple categories:

### 📚 Category-Based Articles

### 📄 Multi-Page Website

## ⚙️ How It Works

1. User enters a claim in the AI detector
2. System simulates:
   - Web search
   - NLP analysis
   - Fact comparison
3. AI generates:
   - Verdict
   - Confidence score
   - Explanation
   - Sources
4. Results displayed dynamically
